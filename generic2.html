RWDx香氛機

本專題為課堂期末專題作品，結合香氛療癒、水氧霧化與物聯網技術， 開發一款可透過手機遠端控制的多功能智慧水氧香氛機， 並整合環境感測與多媒體功能，提升居家睡眠品質與使用便利性。

📌 專案內容

  • 香氛與水氧機整合系統設計
  • 環境感測功能（溫溼度、PM2.5）
  • 助眠應用（精油擴香與音樂播放）
  • RGB燈光氛圍控制
  • 手機網頁遠端控制介面
  • 智慧提醒（空氣品質跑馬燈提示）

🛠 使用技術

  • HTML / CSS / JavaScript
  • Webduino / Arduino 控制系統
  • Blocky 積木式程式設計
  • RWD 響應式網頁設計
  • 手機網頁遠端控制
  • MakerCase + 雷雕外殼製作

💡 我的負責內容

  • 專題主題發想與功能設計
  • Webduino 程式撰寫與測試
  • 網站版面設計與網頁控制整合
  • 電路配置與感測器整合
  • 外殼設計（雷雕與壓克力結構）
  • 作品測試與功能修正
